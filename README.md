# 🏢 동래·연제 전세 4분할 레이더 (JeonseRadar 4X)

> **부산 대장 4대 아파트 맞춤 전세 실시간 모니터링 & 4분할 화면 솔루션**  
> 대상 단지: **동래래미안아이파크** · **레이카운티** · **동래래미안 포레스티지** · **동래 효성해링턴 플레이스**

---

## 🌟 주요 특징 및 구현 내용

1. **🖥️ 1-Click 네이버 부동산 4분할 화면 동시 팝업**
   - 사용자 모니터 해상도를 자동 계산하여 **화면 4분면(좌상, 우상, 좌하, 우하)에 4개 단지의 네이버 부동산 페이지를 정밀하게 분할 정렬**하여 동시에 띄웁니다.
   - 단지별 고유 네이버 지도 레이어 및 전세/가격/평형 필터가 자동 적용된 딥링크로 즉시 연결됩니다.

2. **📊 반응형 2x2 통합 대시보드**
   - 한 웹 화면 안에서도 4개 단지의 전세 매물(동, 층, 가격, 평형, 방향, 공인중개사, 특징)을 나란히 비교 관찰할 수 있습니다.
   - 단독 확대 모드(Solo View)를 지원하여 특정 단지만 크게 집중 분석할 수 있습니다.

3. **🔔 실시간 신규 매물 알림 시스템**
   - **데스크탑 푸시 알림**: Browser Web Notification API를 통해 새 매물 등록 시 바탕화면 우측 하단에 즉시 알림 전송.
   - **오디오 차임음**: Web Audio API 기반의 맑은 딩동 벨 사운드 자동 재생.
   - **인앱 알림 센터 (Notification Drawer)**: 발생한 신규 매물 히스토리를 시간대별로 기록하고 클릭 시 해당 매물로 자동 포커스.
   - **알림 시뮬레이션 테스트**: `[🧪 알림 테스트]` 버튼으로 언제든지 알림 동작을 즉시 체험 가능.

4. **🎯 정밀 맞춤 필터**
   - **거래 유형**: 전세 (`tradeTypes=B1`)
   - **보증금 범위**: 4억 3,000만원 ~ 5억 5,000만원 (듀얼 슬라이더 & 원클릭 프리셋)
   - **면적**: 30평대 (전용 84㎡ 중심 / 30~39평)
   - **단지 규모**: 최소 500세대 이상 (4개 단지 총 13,128세대 모두 대단지)
   - **사용승인연한**: 20년 이내(신축/준신축) vs 20년 이상 vs 전체 필터링

5. **🎨 프리미엄 다크/라이트 테마**
   - 네이버 부동산 그린과 핀테크 슬레이트 블루가 조화된 세련된 다크 테마 및 화사한 클린 라이트 테마 지원.

## 🚀 GitHub Pages 배포 방법

정적 웹 애플리케이션(Vanilla HTML/CSS/JS)으로 제작되어 **GitHub Pages에서 별도 서버나 빌드 과정 없이 100% 즉시 동작**합니다.

### 1단계: GitHub 저장소 생성 및 푸시
```bash
# 1. GitHub CLI 로그인 (또는 웹 브라우저에서 새 저장소 생성)
gh auth login

# 2. GitHub에 새 저장소 생성 및 푸시 (자동 생성)
gh repo create jeonse-radar-4x --public --source=. --remote=origin --push
```

### 2단계: GitHub Pages 켜기
1. 생성된 GitHub 저장소의 **Settings** -> **Pages** 메뉴 이동
2. **Build and deployment** > **Branch**에서 `main` 브랜치 및 `/ (root)` 선택 후 **Save**
3. 약 1분 후 `https://<사용자이름>.github.io/jeonse-radar-4x/` 로 즉시 배포 완료!
